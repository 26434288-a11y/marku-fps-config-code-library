# 本地数据 / Local Data

网站运行后会自动在此目录创建：

The website automatically creates the following files in this directory after it starts:

- `codes.json`
- `settings.json`

这两个文件保存个人配置码，已被 `.gitignore` 排除，不会上传到 GitHub。

These two files store personal configuration codes. They are excluded by `.gitignore` and are not uploaded to GitHub.
